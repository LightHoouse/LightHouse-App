A quieter Lighthouse: create or join a group, then work in your own application.

- Assistants get a floating Record / Pause / Stop toolbar. One session captures accessible controls across applications, without selecting windows or writing step notes.
- Students get a cursor companion. Press **Alt+L** to open chat beside the mouse, with foreground application context captured before chat opens. The latest group recording is selected automatically.
- Answers use the group's recorded steps. Targets are resolved against the student's live window and highlighted without clicking or typing.
- Assistants can disable questions for assessments. Membership is encrypted locally; groups expire after seven days. Typed values and password fields are not recorded.

Download **Lighthouse.Setup.0.2.0.exe**, install, and create a group as an assistant. Record a short demonstration, then join from another client and press Alt+L in the demonstrated application.

Source and packaged tests use two Electron clients, a real isolated MongoDB instance, and native Windows applications. They cover multi-application recording, pause/resume, actual Alt+L input, relocated targets, missing controls, and group closure. Live-service trials additionally exercise the configured AI provider.

Limitations: Windows x64; unsigned installer. Custom canvases, elevated apps, complex menus, and browser DOM targeting are not covered. Guidance does not execute actions or verify task completion. In-memory recording buffers do not survive a crash. Tests against native test applications do not certify every desktop application.

`SHA256SUMS.txt` verifies the installer and `release-manifest.json`, which identifies the source commit and CI run. No automatic updater is included.
