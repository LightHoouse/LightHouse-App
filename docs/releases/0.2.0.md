Create a lab group, record a demonstration, and guide students in their own application windows.

- Assistants create a group and share its code; students join with their name. No database or broker credentials are needed on student computers.
- Pick a Windows application and use Record, Pause, Resume, and Stop / Save. The native recorder captures clicks, typing events, and scroll events on accessible controls. Typed values and password fields are not recorded.
- Students choose a recording and their own application window. Ask a question in Indonesian or follow steps sequentially. The backend limits AI input to that group's recording; the desktop resolves the target again using Windows UI Automation and highlights it without clicking.
- Membership tokens are stored using Windows-backed encryption. Groups and recordings expire after seven days.

Download **Lighthouse.Setup.0.2.0.exe**, run the installer, and open Lighthouse. For a first trial, create a group as the assistant, open a Windows app with accessible controls, select its window, and record a short demonstration. Use another client to join with the code, select the same application, and ask for help.

Automated tests launch two real Electron clients and a separate Windows Forms target, record actual mouse/keyboard input, pause/resume, resolve a moved student window, reject missing targets, and close the group. Backend tests verify group isolation and assistant-only writes. Source and packaged desktop tests run before this release is published.

Limitations: Windows x64 only; the installer is unsigned. Custom-drawn controls, elevated applications, complex menus, and browser DOM-specific targeting may not be readable. Guidance does not execute actions or verify that the student completed a step. Closing while recording requires saving first; recording does not survive a process crash. A successful test on the Windows test application does not certify every desktop application.

`SHA256SUMS.txt` verifies the installer and `release-manifest.json`, which records the source commit and CI run.
