# Lighthouse 0.3.2

- Register `.lighthouse` as a Lighthouse Recording with the supplied Lighthouse icon in Windows Explorer.
- Apply the same branding to the installer/uninstaller, installed executable, desktop and Start Menu shortcuts, window/taskbar and tray.
- Double-click a recording to open a preview with its name, date, action count and applications. Choose an assistant group before confirming import; opening a file never uploads it automatically.
- Reuse the running app for files opened from Explorer. Separate test profiles remain isolated.
- Replace immediate UI import with the same preview flow and fix the student-row chevron.

The installed Windows release registers the file type; a source/unpacked build alone does not register Explorer associations. Windows may require selecting Lighthouse through Open With if another default was previously chosen. Existing recording files remain compatible.
