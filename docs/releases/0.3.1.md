# Lighthouse 0.3.1

Includes the Lighthouse logo, Quicksand UI, classroom management by student, local IP/device metadata visible to assistants, shortcut page, encrypted recovery, portable recording files and gesture guidance introduced in 0.3.0.

Fixes closed freehand strokes: a gesture that returns to its starting point remains a drag path instead of being classified as a click. A native regression test records a closed stroke and checks the exported path.

Canvas gestures require a unique accessible target. Figma/Miro document transforms, standalone tool hotkeys, stylus pressure and touch remain uncertified or unsupported; see README and action-coverage.md. Pointer-path acknowledgement does not certify the drawing result. Windows installer is unsigned.
