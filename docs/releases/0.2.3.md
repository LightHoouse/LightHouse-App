Cursor-following chat and a pointing companion.

- The input bubble and answer card follow the mouse while open, flipping above the input near the bottom edge and left near the right edge, within the current monitor.
- The blue companion moves to a resolved recorded control, waits for a click on that target, then returns to following the mouse. No rectangular highlight is displayed and the real mouse is never moved by guidance.
- A three-dot thinking animation is replaced by real streamed text as soon as provider deltas arrive.
- Previous target guidance is cleared when a new question starts. Chat opens in compact mode.
- Added opt-in extended-session and real Windows Calculator E2E scenarios, alongside the isolated release smoke test.
