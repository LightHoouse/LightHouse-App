# Lighthouse 0.3.0

- Record across accessible Windows applications without saving individual steps.
- Restore encrypted pending actions after a crash, paused until the assistant resumes. Upload retries reuse event IDs; a pending Stop completes after synchronization.
- Capture timestamped UI observations, ancestor context, supported patterns and relative target bounds. Backend stores canonical JSON alongside the compatibility format; no screenshots or typed contents are recorded.
- Keep distinct actions in AI candidates when a long demonstration repeatedly uses the same controls, including relevant actions in another app.
- Distinguish a target click from an observed UI outcome. A click alone never means the entire task succeeded.
- Retain real streamed answers, cursor-following chat, edge-aware placement and the blue target companion.

Windows UI Automation targets only. Custom canvases, DOM-specific locators, arbitrary elevated applications and inferred prerequisites remain unsupported. Groups expire after seven days; closed/expired groups cannot receive recovered uploads. The installer is unsigned and has no automatic updater.

CI includes source and packaged two-client flows, offline/crash recovery, placement checks and outcome/journal regression tests.
