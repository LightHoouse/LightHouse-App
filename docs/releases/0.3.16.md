# Lighthouse 0.3.16 — Windows

Download the .exe installer for Windows x64. Run it to install or upgrade Lighthouse. Downloading alone does not update an existing installation.

Fixes `Alt+L` immediately toggling chat closed due to Windows `WM_HOTKEY` key-repeat while synchronous focus calls blocked the event loop; adds a 400ms hotkey debounce and makes the Win32 focus fallback non-blocking.

macOS and iOS installers are not available in this release. macOS needs native recording and encrypted-storage implementations before packaging can be enabled. iOS needs a separate client and does not support desktop-style global cursor guidance.
