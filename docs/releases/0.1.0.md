First downloadable Windows release of the Lighthouse desktop prototype.

- Open the desktop panel, display a guide demo, and dismiss it.
- Receive MQTT text guidance with TLS verification and delivery acknowledgments when configured for a lab.
- Source and packaged Electron smoke tests check the real panel, preload bridge, overlay text, and dismiss behavior before publication.
- Live UI targeting, recording, step verification, and the classroom dashboard are not implemented yet. This release does not provide the full classroom workflow.

Download **Lighthouse.Setup.0.1.0.exe**, run the installer, then open Lighthouse. The panel and demo work without broker configuration; lab messaging requires client credentials. The installer is unsigned.

`SHA256SUMS.txt` verifies the downloads. `release-manifest.json` records the version, source commit, Electron version, platform, and verification workflow.
